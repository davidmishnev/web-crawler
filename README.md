# Web crawler

Краулер на Go: последовательно обходит ссылки в пределах исходного хоста, извлекает текст HTML/PDF и сохраняет документы в PostgreSQL.

## Запуск

Требуются **Go 1.25.4+** и PostgreSQL. Создайте базу данных и задайте строку подключения:

```sh
export DATABASE_URL='postgres://crawler:password@localhost:5432/crawler?sslmode=disable'
go run ./cmd/crawler -max-pages 100 -timeout 15s -delay 200ms https://example.com/
```

Флаги указываются перед URL. `go run ./cmd/crawler -h` выводит справку. Если локальный Go старее требуемого, обновите его или разрешите стандартный автоматический выбор toolchain через `GOTOOLCHAIN=auto`.

Таблица `documents` и индекс по URL создаются при запуске; пользователю БД нужны права на создание/изменение таблицы. Начальная таблица с полями `url`, `title`, `text` дополняется новыми колонками. Если в существующей таблице есть повторяющиеся URL, создание уникального индекса завершится ошибкой: дубликаты нужно предварительно разрешить вручную.

## Поведение

- По умолчанию в очередь попадает до 100 URL, пауза между страницами — 200 мс, тайм-аут запроса и операции БД — 15 секунд.
- Относительные ссылки разрешаются с учетом конечного URL после редиректов и HTML `<base>`. Фрагменты удаляются, повторные URL не добавляются в очередь. Query-параметры сохраняются.
- Ссылки и редиректы на другой хост (включая поддомены и другой нестандартный порт) не обходятся. HTTP → HTTPS на том же хосте разрешен.
- HTML: заголовок, текст, ссылки, автор, язык, описание и дополнительные метатеги. Содержимое `script`, `style`, `noscript`, `template` исключается. Учитывается кодировка документа.
- PDF: текст, заголовок и автор. OCR и выполнение JavaScript не поддерживаются.
- Сохраняются также MIME-тип, SHA-256 исходного содержимого и время обхода UTC. Повторный запуск обновляет документ по URL.
- Ответ ограничен 20 МиБ. Неуспешные HTTP-ответы, ошибки разбора и неподдерживаемые типы пропускаются с записью в журнал. Ошибка БД останавливает процесс; запуск без сохраненных документов завершается с ошибкой.
- Ctrl+C/SIGTERM отменяет активные операции. PDF-разбор проверяет отмену между страницами.
- `robots.txt` пока не обрабатывается; запускайте для сайтов, на обход которых у вас есть разрешение.

## Проверки

Все тесты собраны в каталоге `tests/` и проверяют пакеты через их экспортируемый API.

```sh
go test ./...
go vet ./...
```

Для проверки схемы, сохранения всех полей и обновления по URL задайте отдельную тестовую БД (тест создает таблицу `documents`):

```sh
TEST_DATABASE_URL='postgres://crawler:password@localhost:5432/crawler_test?sslmode=disable' go test ./tests -run TestStorageIntegration -count=1
```

Без `TEST_DATABASE_URL` интеграционный тест хранилища пропускается; остальные тесты работают без PostgreSQL.
